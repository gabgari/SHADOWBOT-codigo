# App de control (Flutter)

Consola del operador de SHADOW BOT para una tablet Android en horizontal.

- Video de las dos cámaras: ESP32-S3 (MJPEG) y Tapo C110 (RTSP) o el video anotado del servidor de visión.
- Manejo con controles en pantalla o con un DualShock 4 por Bluetooth.
- Lectura del sensor MQ-2, alertas, grabación de video y fotos.
- Descubrimiento automático de las placas y del servidor de visión en la red (UDP).
- Descripción de escena con la API de Gemini (la clave la escribe cada usuario en Ajustes; no va en el código).

```bash
flutter pub get
flutter run
```
